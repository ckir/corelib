Pure Yahoo proto-decode mapper + YahooDriver (shared engine). YahooDriver: pure proto-decode mapper + one WebSocket connection attempt. Dual-mode: every decoded message yields the byte-identical raw JsPricingData (so on_pricing always fires) plus 0/1/2 unified MarketEvents.

Structs§

YahooDriver
One Yahoo real-time stream connection. The supervisor owns the reconnect loop; this driver performs a single attempt (connect → subscribe → pump). Yahoo is unauthenticated and single-channel; the redb DB (shared Arc<Database> from the host) is the single source of truth for subscriptions, read fresh (bare keys) on every (re)connect.

parse_yahoo_message
Decode one Yahoo WS text frame into the raw payload + zero/one/two unified events. Returns None only when the frame is not a decodable pricing envelope (skip frame). The raw JsPricingData is ALWAYS present when Some (so on_pricing always fires), even when the uni vec is empty (heartbeats / all-zero-price messages).
