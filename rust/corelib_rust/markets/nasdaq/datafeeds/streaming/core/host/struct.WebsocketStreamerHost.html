Struct WebsocketStreamerHost 

Source 
pub struct WebsocketStreamerHost { /* private fields */ }
Expand description

Shared coordination state. Pump consumes MarketEvents and calls the provider’s typed TSFNs. Like the b-1 Alpaca fix, we store the monitor task (which owns/awaits the supervisor) and the pump task; the supervisor itself exits via stop_tx.
